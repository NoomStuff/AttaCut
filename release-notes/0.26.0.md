## Changes

- Playback controls stay centered in compact windows. Clip start, end, and duration sit together on the right, with editable times highlighted on hover or focus.
- Panels keep a subtle transparent background. Buttons and fields use lighter backgrounds, while selected tabs have a stronger highlight.
- Controls use consistent sizing and spacing. Timeline labels and settings headings are easier to read.
- Audio and navigation menus work more consistently with the keyboard. Audio menus stay inside the window at compact sizes.
- Creating an export folder uses the normal confirmation style. Destructive warnings remain reserved for changes that need them.

## Downloads

- Windows: use `AttaCut-0.26.0-win-x64-Installer.exe` to install, or `AttaCut-0.26.0-win-x64.exe` for the portable app.
- macOS: choose `mac-arm64` for Apple Silicon or `mac-x64` for Intel. Both have `.dmg` and `.zip` downloads.
- Linux: choose `linux-x86_64.AppImage` for 64-bit Intel or AMD PCs, or `linux-arm64.AppImage` for 64-bit ARM devices. Make the AppImage executable before opening it.
