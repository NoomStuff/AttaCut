## Changes

- Windows upgrades keep the existing installation folder and desktop shortcut choice without repeating the setup questions.
- Export notifications show the saved clip names and clearer completion messages.
- Fixed waveform fading at clip and viewport edges, and corrected keyframe marker rendering.
- The image export panel closes after saving.
- Update downloads no longer replace an existing file with the same name.

## Downloads

- Windows: use `AttaCut-0.25.0-win-x64-Installer.exe` to install, or `AttaCut-0.25.0-win-x64.exe` for the portable app.
- macOS: choose `mac-arm64` for Apple Silicon or `mac-x64` for Intel. Both have `.dmg` and `.zip` downloads.
- Linux: choose the `linux-x86_64.AppImage` download for 64-bit Intel or AMD PCs, or `linux-arm64.AppImage` for 64-bit ARM devices. Make the AppImage executable before opening it.
