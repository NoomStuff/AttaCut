## Changes

- Playback waits for the selected frame before starting. Pausing during preview preparation keeps playback paused when the preview is ready.
- Image exports use the selected source frame, including the last included frame at a clip's end. Exporting an image remains available when the preview cannot play the file.
- Reduced the code loaded at startup and memory use when resolving frame boundaries in long undo histories.
- Choosing "Don't save" when closing a project keeps discarded edits out of recovery, even if an autosave is still pending.
- Playback stays in view when zooming near the end of a recording.

## Downloads

- Windows: use `AttaCut-0.25.1-win-x64-Installer.exe` to install, or `AttaCut-0.25.1-win-x64.exe` for the portable app.
- macOS: choose `mac-arm64` for Apple Silicon or `mac-x64` for Intel. Both have `.dmg` and `.zip` downloads.
- Linux: choose `linux-x86_64.AppImage` for 64-bit Intel or AMD PCs, or `linux-arm64.AppImage` for 64-bit ARM devices. Make the AppImage executable before opening it.
